# 粗野主义生成器 · BRUTALIST GEN

一个纯前端的**粗野主义（Brutalism）界面配置器**。可交互地生成硬边、硬阴影、高对比、无柔和渐变的组件样式，并一键导出可直接运行的 HTML / CSS 代码。

> 在线体验：<https://fanqin314.github.io/Brutalist-Web-Design/>

---

## 界面一览

```

│ 顶栏  品牌标识 · 撤销/重做 · 随机组合 · 重置 · 分享链接 · 导出/导入    │
├────────────────────────────────────────────────────────────────────┤
│ 模式栏  按钮 / 卡片 / 复选框 / 开关 / 输入框 / 徽章 / 单选组 / 进度条   │
│         滑块 / 下拉 / 警告条 / 表格 / 导航栏 / 标签页 / 整页           │
├──────────────────────────┬─────────────────────────────────────────┤
│ 控制面板                 │ 舞台                              │
│  内容 · 预设方案 · 配色   │  组件预览（默认 / 悬停 / 按下        │
│  形状 · 排版 · 表面图案   │  / 聚焦 / 禁用 五态矩阵）           │
```

- **左侧面板**：编辑内容、选色、调形状/排版/图案/交互，所有调整即时生效。
- **右侧舞台**：居中为组件实时预览，下方同步展示可复制的 HTML / CSS 代码。
- **无构建步骤**：零依赖、零打包，`index.html` 直接双击即可运行。

## 核心功能

**内容与配色**
- 直接输入按钮文字 / 卡片标题 / 标签文字等。
- **23 套预设配色**：荧光绿 / 经典 / 反色 / 火红 / 纸感 / 柠檬黄 / 电光青 / 泡泡糖 / 电光蓝 / 葡萄紫 / 墨绿 / 铁锈红 / 血红 / 薄荷 / 水泥灰 / 蓝图 / 焦糖棕 / 鎏金藏蓝 / 焦橙 / 甜莓粉 / 香芋紫 / 海泡青 / 银灰。
- 四色独立调节：背景、文字、边框、阴影。

**形状与排版**
- 边框粗细、圆角、旋转、三向阴影（X / Y / 模糊）、横纵内边距。
- 字体族（Mono / Sans / Serif / Impact / Arial Black）、字重、字号、字间距、全大写开关。
- 表面图案：纯色 / 斜条纹 / 网格 / 圆点。

**状态与交互**
- **五态矩阵**：默认 / 悬停 / 按下 / 聚焦 / 禁用 同屏预览。
- 悬停摆正、悬停上浮、阴影膨胀、悬停反色、按下抖动 等交互动效。

**工作台**
- 预览底色（网格 / 纯白 / 深底 / 棋盘）与设备宽度（自适应 / 390 / 768 / 1024）。
- 代码语法高亮、压缩输出。
- **全屏预览页面**：单独查看生成的完整页面，不受工作台干扰（Esc 关闭）。

**导出与协作**
- 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）。
- 随机组合、重置。
- 一键 **复制 / 导出 HTML**（单文件、可双击运行）。
- 分享链接（当前设置编码进 URL）、导出 / 导入 JSON 配置。

## 目录结构

```
.
├── index.html            # 页面骨架（顶部栏 / 模式栏 / 面板 / 舞台）
├── css/
│   └── base.css          # 工作台自身样式
└── js/
    ├── core.js           # 共享常量、样式变体表、字体表、组件注册表
    ├── data.js           # 全部预设方案（PRESETS）+ 调色板（单一事实源）
    ├── interact.js       # 预览区交互脚本（导出时内联为同一份）
    ├── render.js         # 组件渲染：由 state 生成 HTML/CSS
    ├── app.js            # 启动、事件聚合、历史栈、分享/导出/导入
    └── components/
        ├── button.js  card.js  checkbox.js  switch.js  input.js
        ├── badge.js   radio.js progress.js   slider.js   select.js
        ├── alert.js   table.js nav.js        tabs.js     page.js
```

## 技术说明

- **纯原生**：`HTML + CSS + JavaScript`，无框架、无打包器、无外部依赖。
- **单一事实源**：所有预设（颜色 / 形状 / 交互）集中在 `data.js` 的 `PRESETS`；样式变体集中在 `core.js` 的变体表；组件渲染统一由 `render.js` 驱动。
- **可迁移**：复制的代码 / 导出的 HTML 均为独立样式块，可直接嵌入任意页面。
- **事件收敛**：交互事件绑定聚合到单一入口，避免重复执行；渲染通过 `requestAnimationFrame` 合并高频输入。
